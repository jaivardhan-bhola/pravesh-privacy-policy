# Pravresh Privacy Policy

Privacy Policy page for Pravresh by CRISPR - Smart Entry and Exit System

## Quick Deployment to GitHub Pages

1. Go to your repository Settings
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Select your branch (e.g., `main` or `copilot/create-privacy-policy-page`)
5. Select the root folder `/` 
6. Click "Save"
7. Your privacy policy will be live at: `https://[username].github.io/pravesh-privacy-policy/`

## Customization

Before deploying, you may want to update the placeholder contact information in `index.html`:
- Phone number: Line 230 contains `[Contact Number]` - replace with actual contact details
- Email: `privacy@pravresh.edu` can be updated to your actual email
- Effective Date: Currently set to February 3, 2026
